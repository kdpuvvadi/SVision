PLC handshake documentation

Modbus TCP and OPC UA share one handshake. Measure runs on a worker thread, not on the web request path.

Setup in SVision

  1. Open a scene, add tools, and choose/store an image (or use USB/GigE later).
  2. Click PLC in the top bar.
  3. Set Production scene to the scene that should run on trigger.
  4. Enable Modbus TCP and/or OPC UA, set bind host/port/endpoint, then Save.
  5. Until a live camera is connected, a trigger measures the currently stored image for that production scene.

Shared signal contract

Both protocols expose the same bits. The PLC owns reject timing from DONE.

DirectionNameRule
InTRIGGERRising edge starts one measure. Ignored while BUSY. Cleared after the edge so writing 1 again retriggers.
OutREADYProduction scene ready (stored image or live camera).
OutBUSYMeasure running.
OutDONEShort pulse with the result bits (see Result pulse ms in PLC settings).
OutOK / NGMutually exclusive. Pulsed with DONE, then cleared (not latched).
OutERRORFault pulse (no production scene, no image, camera failure, exception).

Judgment codes (holding / OPC node): 0 idle, 1 OK, 2 NG, 3 ERROR. Holding values stay until the next measure; coil outputs pulse then clear.

Modbus TCP

Connection

  • SVision is the Modbus TCP server. The PLC (or Open ModScan) is the client.
  • Default bind: 0.0.0.0:1502 (Port `1502`).
  • Default unit / slave id: 1.

OPC UA

Connection

  • SVision is the OPC UA server.
  • Default endpoint: opc.tcp://0.0.0.0:4840/svision/
  • From another PC use the IPC LAN IP, for example opc.tcp://192.168.1.10:4840/svision/.

Typical PLC sequence

1. Wait READY = 1
2. Pulse TRIGGER = 1 (rising edge)
3. Wait BUSY = 1, then BUSY = 0 (or wait DONE pulse)
4. Capture OK / NG / ERROR during the result pulse
   (or read Judgment holding / OPC node — stays until next cycle)
5. Reject delay and conveyor timing stay in the PLC

Open ModScan test

  • Connection: TCP to IPC IP, port 1502, device id 1.
  • Point type: 01 Coil Status.
  • Address base: 1-based, start 1, length 7 (or up to 50).
  • Write coil 000001 = 1 to trigger. Watch 000003 BUSY, then a short pulse on 000004 DONE and 000005/000006 OK/NG.
  • Holding registers: point type holding, start 1 (or 40001 depending on tool), length 2.

Notes

  • Web Measure is for debug; production should use Modbus/OPC TRIGGER.
  • Only one measure runs at a time. Triggers while BUSY are ignored.
  • Firewall: allow TCP 1502 (Modbus) and 4840 (OPC UA) if connecting from another PC.
